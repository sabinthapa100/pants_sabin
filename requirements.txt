# PyTorch is intentionally NOT pinned.
#
# The correct wheel depends on your GPU, CUDA runtime and platform. Install it
# first from https://pytorch.org/get-started/locally/, then run
# `pip install -r requirements.txt`. Pinning a CUDA build here would make the
# repository non-portable: the Colab runtime and a local laptop do not use the
# same wheel, and both are used in this study.
#
# Stacks this code has actually run on:
#   laptop  Python 3.11.15, PyTorch 2.13.0+cu126, MONAI 1.5.1
#   Colab   Python 3.12.13, PyTorch 2.11.0+cu128, MONAI 1.5.1
#
# monai and nnunetv2 both declare a torch dependency, so an existing correct
# torch install is respected rather than replaced.

# --- required at runtime: data, model, inference -------------------------
numpy
nibabel
monai==1.5.1          # SegResNet, transforms, sliding-window inference
# scipy.ndimage.label finds lesion connected components in postprocessing.py.
# It arrives transitively with monai, but src/ now imports it directly, so it is
# declared rather than assumed.
scipy
